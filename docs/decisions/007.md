# ADR 007: Private planning and public-safe history

Status: accepted for the bootstrap.

## Decision

Keep tracker/session/business data outside the independent public repo. Public docs/contracts/tests remain self-contained and generalized.

## Consequences and rejected alternatives

Ignoring files alone is not a publication boundary. Runtime engineering guides and coding instructions are distinct. No private task tracker is required by public users.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
