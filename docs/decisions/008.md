# ADR 008: Targeted tests and disposable pre-1.0 state

Status: accepted for the bootstrap.

## Decision

Run impact-selected checks and planned integration batches. Reset only explicitly disposable pre-1.0 state instead of preserving transient schemas.

## Consequences and rejected alternatives

No full suite per turn. No fake mock/skip acceptance. Valuable originals and private reference/tracker data are never disposable by inference.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
