# ADR 004: Filesystem-first artifacts and on-demand tools

Status: accepted for the bootstrap.

## Decision

Store immutable bytes locally through an app storage interface; support optional S3/Garage for shared storage. Run native packs only for work.

## Consequences and rejected alternatives

Object stores do not own engineering revisions. No mandatory idle CAD/compiler/model processes. Users receive prebuilt images rather than installing toolchains on the host.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
