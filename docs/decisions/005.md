# ADR 005: Reuse domain functionality before rewriting

Status: accepted for the bootstrap.

## Decision

Inspect pinned prior modules and retain useful implementations, tests and source provenance. Generalize private/process-specific assumptions.

## Consequences and rejected alternatives

WireViz is an optional exporter; it does not replace capable coax/cable visualization. Typst is not a mandatory rewrite of working document generators.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
