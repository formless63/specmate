# ADR 003: Compact PostgreSQL deployment

Status: accepted for the bootstrap.

## Decision

Use standard PostgreSQL 18 for app, Temporal and SQL Visibility in separately owned databases. Enable pg_trgm and diagnostics; optional pgvector.

## Consequences and rejected alternatives

No required TimescaleDB or Elasticsearch. Add workload isolation/search systems only after measured need. Temporal adapter names do not select an obsolete database major version.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
