# ADR 001: Python application with browser TypeScript

Status: accepted for the bootstrap.

## Decision

Use Django/Ninja/Pydantic as the authoritative application and React/Vite for the workshop. Preserve useful TypeScript presentation/geometry and on-demand exporters.

## Consequences and rejected alternatives

A TypeScript starter remains possible but is not selected; keeping two full backends duplicates authority. Python-first does not mean one native dependency environment.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
