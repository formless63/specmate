# ADR 009: Initialization inside existing services

Status: accepted for the bootstrap.

## Decision

Package approved app/Temporal schema tools into existing startup paths with locking and clear readiness. Keep UI for operators.

## Consequences and rejected alternatives

No dedicated init/migration/admin-tools services by default. No development-only embedded Temporal disguised as the production deployment. No automatic schema generation or destructive repair at startup.

## Reconsideration

Revisit only with concrete compatibility, measured resource/maintenance, licensing or
engineering evidence. Record the changed requirement and affected contracts. A coding
agent's familiarity with another stack is not sufficient reason to reopen the choice.
