# Specmate identity

Use **Specmate**, **SPECMATE**, or **specmate**. Do not capitalize the middle of
the name. The name combines specifications and a helpful counterpart, with a
quiet nod to checkmate: reaching a well-supported engineering decision.

The symbol is an original drawing of opposed stepped shapes around a shared
registration mark. Its open S suggests mechanical fit and alignment. It is
identification, never a passing check, certification, or release stamp.

Use the `Brand` and `BrandSymbol` components in the application. The standalone
symbol is available at `frontend/public/brand/specmate-symbol.svg`; it uses
`currentColor`. Give it at least four drawing units of clear space. Use the
simplified favicon at 16 pixels; larger versions retain the center datum.

Lettering uses the existing Geist Mono face, medium or semibold, with restrained
tracking. Body text continues to use Geist. Keep the existing font licenses.
Use Schematic Bench's theme tokens: amber for the symbol in the workspace and
ordinary text color for the wordmark. Printed identification is monochrome.
Dark and light appearances follow the application's OS preference.

Specmate is an engineering tool. Identify the application without promotional
taglines, sales panels, mascots, pricing cues, or decorative cloud imagery.
Use direct language about the item and action. Keep missing facts and unresolved
checks visible; the brand must never substitute for evidence.
