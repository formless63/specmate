# Application screenshots

These are browser captures of Specmate at source revision
`41bc59caf9e89561b5a01350e5aecdcf50053a11`, using synthetic demonstration records.
They are actual application views, not product mockups or imported customer designs.

- `cable-workbench.png`: Demo console to RGB monitor cable, frozen revision 3.
- `wire-stock.png`: Demo six-coax AV stock, frozen revision 2, Section view.
- `board-record.png`: Demo AV adapter board, frozen revision 2, declared connectivity.

The stock and board originate in the synthetic AV demonstration in
[`demo_seed.py`](../../../backend/src/specmate/operations/demo_seed.py). The cable is
an original synthetic fixture built through application operations from the corresponding
demo ports, end assemblies, stock and intent. Generic Console A/monitor identities do
not represent a specific physical product. No proprietary imported design was renamed
for these images.

Captured with Chromium at 1600 × 900 in dark mode. Only the account header label was
substituted with `demo-engineer`; engineering records and results were not altered.
The browser used read-only inspection and source resolution. No native tool was run
for these captures. Missing geometry and materials remain visibly unknown; board traces
show declared connectivity, not physical PCB routing or manufacturing approval.
